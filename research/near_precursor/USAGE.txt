NEAR 선물 상승/하락 이전 구간 연구

목표: 현재 움직임에 따라가는 임시 momentum-alert 조건을 전조 모델로 오해하지
않고, 실제 NEAR 가격의 +/-5%, +/-10% 움직임 이전에 반복되는 차이를 분석한다.

실행 (레포 최상위):
  node research/near_precursor/fetch.mjs
  python3 -m unittest discover -s research/near_precursor -p 'test_*.py'
  python3 research/near_precursor/study.py
  python3 research/near_precursor/report.py

Node22+ 및 Python numpy/pandas/scipy/scikit-learn/pyarrow/matplotlib 필요.
fetch는 최근183개 UTC 완결일의 Bybit linear15분봉 NEAR/BTC/ETH와 NEAR의
15분 미결제약정, 실제 정산 펀딩비를 수집한다. 기존 data.json.gz는 덮어쓰지 않는다.
output/manifest.json에 자료와 사전 프로토콜 해시를 보존한다.

원래 움직임 시작점을 알 수 없으므로 운영상 정의를 명시한다:
시점t 이후1시간 종가가 해당 방향2% 이상 움직이고24시간 내 고가/저가가
해당 방향5%/10%에 도달하면 후보 시작점이다. 방향/목표별 첫 시작점을 고른
뒤24시간을 띄운다. 정확한 경제적 시작점의 증명이나 가능한 모든 움직임의
목록은 아니다. 기준을 바꾸려면 별도 연구로 기록한다.

전조 판단은 시작점15~60분 전만 성공으로 센다. 이미 직전1시간에1% 이상
움직인 의사결정은 제외한다. 정답에는25시간의 미래 자료가 필요하며 미성숙
구간을 실패로 세지 않는다. 미래자료는 정답에만 사용한다.

학습90일/기준설정30일/검증60일, 경계에서25시간 정답 제거와48시간 간격 적용.
훈련에서 도달 가능한 서로 다른 사건20건, 기준설정에서5건이 없으면 학습하지 않는다.
표본 부족을 해결하기 위해 검증 결과를 본 뒤 기간/기준을 바꾸지 않는다.
방향별 독립6시간 재알림을 가정한 연구 평가이며 운영 알리미의 양방향 공유
재알림 정책이나 체결 수익률과 동일하지 않다.

학습구간 사건1시간 전과 같은 시간대/비슷한 과거 변동성의 비사건 구간을 짝지어
비교한다. 작은 표본의 중앙값 차이는 발견 후보이며 검증된 신호가 아니다.
펀딩비/미결제약정은 기록시각15분 후 사용 가능하다고 가정한다. 과거 API 실제
공개 지연을 복원한 것이 아니므로 실시간 재현은 별도 검증해야 한다.
과거 호가/체결방향 데이터가 없으므로 매집, 매도 우위, 강제청산을 추정 사실로 쓰지 않는다.

output/report.json 및 report.html: 실제 자료 품질/사건 수/가설 비교/학습 가능 여부.
output/model_locks.json: 지원 조건을 만족한 경우에만 생성. 자동 실전 배포하지 않는다.
원본 대량자료는 Git에 올리지 않는다. protocol/source와 실행 결과 보고서를 구분한다.
