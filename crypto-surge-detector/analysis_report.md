## 5. 해석 가이드

- **Cohen's d 해석**: |d| >= 0.2 작은 효과, >= 0.5 중간, >= 0.8 큰 효과
- **점수 해석**: 0~100 범위, 높을수록 과거 급등 전 패턴과 유사
- **주의**: 과거 패턴이 미래를 보장하지 않음. 시장 구조 변화, 규제, 거시경제 미반영
- **활용**: 관심 목록 필터링 용도. 단독 매매 시그널로 사용 금지
- Level A 모델은 극단적 급등(100%+)에 특화, 일반적 상승은 Level B/C 참고
